# 文字优先内部试用实施路线

日期：2026-09-20。依据：D-035、V0.1 PRD §0.1。本文是实施排期，不替代产品需求。

## 目标与范围

尽快形成可实际试用的文字生活记录闭环，验证记录、行动与回顾的价值。可靠性优先于编辑器装饰，不增加富文本、标签系统、AI 或未来版本功能。原始语音仍为 V0.1 P0，但暂停新增语音实现；已通过验证的 schema v2 和迁移保留。

## 分批顺序与依赖

| 批次 | 最小交付与出口条件 | 依赖 / 产品闸门 |
|---|---|---|
| T1 | 文字 Capture 往日回看；随后独立批次实现本地删除。保存、重启回看、失败状态和原文保护可验证 | 现有文字存储；删除前明确删除确认、数据清理和未来同步边界，不自行推断 |
| T2 | 无 Task 也可开始的 Session，暂停/恢复/结束及异常修复 | T1 基础；先完成时间状态契约及独立审查 |
| T3 | Session 内文字 Entry/Spark，保存不结束行动，原文可回看 | T2；不把所有 Capture 自动解释为 Spark 或 Task |
| T4 | Timeline 汇集已实现记录；Unknown 可保留；轻量 Daily Review 可跳过；基础 Life Area | T2/T3；落实 PD-04 等未决项。依赖 Task 的统计在 T5 补齐，不提前伪造 |
| T5 | 基础 Task/DDL，并连接 Session、Timeline 和 Review | T2；提醒与下一步规则按 PRD/决策，不任意新增调度规则；T4/T5 可按实际依赖拆交 |
| T6 | 跨日、离线、重启及 Windows/Android 文字试用，收集实际反馈 | 上述文字闭环；阻断缺陷优先，不追求无限完善 |
| 后续 | 恢复原始语音，再完成隐私/同步等剩余 P0 和全量 V0.1 验收 | 语音沿用 D-031/032/033；同步和删除传播需各自规格与验证 |

## 当前有界批次：T1a 往日文字回看

需求依据：V0.1 §3.1/§3.2、V0-P0-08/12；Master PRD §9。

- Now 保持今天的缩略时间线；独立 Timeline 默认今天，可选日期、回到今天、打开原始内容。
- 按设备当前本地自然日查询 `[当日零点, 次日零点)`；沿用现有存储排序和原始时间 offset 展示，不修改记录时间。
- 历史选择保持为所选日，重新进入默认今天；日期切换不把旧日记录冒充为新日结果。
- 保留空态、读取失败状态和 Capture 入口；从历史页 Capture 仍使用实际保存时刻，不进行隐式补记。
- 不修改数据库、原文或隐私；不新增删除、编辑、Session、Unknown 推断或媒体功能。
- 必须验证日期边界、原文回看、取消选日、回到今天、读取失败及现有文字回归；独立 Reviewer 检查需求和 diff。
